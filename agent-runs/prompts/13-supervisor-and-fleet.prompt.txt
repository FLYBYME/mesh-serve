--- 3. The fleet ------------------------------------------------------------

`node.hello`, `node.assign`, `node.status`, gated `operator`.

**Identity is the hostname.** Not the per-process `nodeID` the mesh mints —
`publish-a7f3k` changes every restart, and a rebooted VPS must be the same row.

**Desired state only.** The row holds the assignment: which manifest entries this
node should be running. Observed state is Registry presence — read it, do not
copy it into the row. `cdn/schema/edge.ts` explains why a second heartbeat is
worse than none, and that reasoning is binding here.

**Assignment is a switch.** `node.assign` results in `supervisor.service_start` /
`service_stop` on the target node. No code is shipped; every node carries the same
services and genesis decides which run. Live, not boot-only: a node already
running takes on or drops an entry without restarting.

**`node.status` answers what this node is running and what it is connected to.**
It is the direct answer to *"stale mongo, stale k3d, nobody knows anything"* and
it is the most valuable single call here. Do not leave it for later.
