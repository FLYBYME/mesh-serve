--- 1. One builder for CallShape, so one exposure has one hash ---------------

`describeExposure` (descriptor.ts:167) builds `CallShape` **with** `errors`. The
runtime route table (routes.ts:128) builds it **without** — no `errors` key at
all, so `hashShape` folds in `[]` for every call. Both then call `hashShape`.

So the same exposure hashes to two different values depending on which path
produced it, for any contract that declares failures. The generated client bakes
one; the `x-exposure-shape` response header carries the other. **A client can be
reported stale while being perfectly current**, and the report is believable,
which is what makes it expensive — a live console failed this way today with
every call returning the word "stale".

One builder, used by both. If the two genuinely need different fields, that is a
decision to state out loud rather than a difference left in two `.map()` calls
thirty lines apart.

**Add a test that the descriptor's `shapeHash` and the route table's `shapeHash`
agree for an exposure containing a contract that declares errors.** That test
fails today; write it first and watch it fail.

--- 2. A group edit converges, through an event ------------------------------

`node.reconcile` exists and works. Nothing calls it. Editing a group updates a
row and leaves every machine in that group running exactly what it was running —
which is the failure that storing groups by reference rather than by expansion
was chosen to avoid, arriving one layer up.

`group.update` should cause the nodes referencing that group to reconcile.

**Not inline.** A write that blocks on starting services across seven machines is
a write that times out, and a group edit is a small write. Use the mechanism this
repository already uses everywhere: CRUD emits a scoped event, something acts on
it.

Decide and say in your plan: whether `group.create` and a `node.assign` that adds
a group also converge, and what happens when one node in the group fails to
reconcile. **It must not stop the others** — `node_reconcile` already gets that
right and the event handler must not undo it.
